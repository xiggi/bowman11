# bowman11

A static-first yearly camping trip microsite for friends.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

Content lives in `src/content/`. RSVP and coordination stay external (Google Forms, Doodle, When2Meet, etc.).

## Commands

```bash
npm run dev    # local development
npm run build  # production build
npm run lint   # eslint
```

## Deploy

Push to GitHub and connect the repo to Vercel. No database, auth, or API routes in v1.
